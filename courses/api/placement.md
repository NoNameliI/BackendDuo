# Тест для тех, кто работал с API

Девять вопросов в трёх блоках. Если в блоке правильных ответов хотя бы два, его уроки засчитываются, и вы начнёте с первой незнакомой темы. Мир «За пределами REST» (GraphQL и gRPC) тест не засчитывает.

## task api-pl-status

```json
{
  "type": "choice",
  "title": "Код для созданной записи",
  "hints": ["Подумайте, каким кодом сервер сообщает, что ресурс создан."],
  "options": ["`200 OK`", "`201 Created`", "`204 No Content`", "`302 Found`"],
  "answer": [1],
  "explanation": "`201 Created` сообщает, что запрос создал новый ресурс; обычно в ответе есть его данные и заголовок `Location` с адресом. `200` — общий успех и не говорит, что запись новая, `204` — успех без тела, а клиенту нужен созданный заказ, `302` — перенаправление на другой адрес."
}
```

Клиент отправил `POST /orders`, и сервер создал новый заказ. Какой код ответа подходит лучше всего?

## task api-pl-path-param

```json
{
  "type": "choice",
  "title": "Параметр пути в FastAPI",
  "hints": ["Посмотрите на аннотацию типа у параметра функции."],
  "options": [
    "Функция получит строку `abc` и упадёт с кодом 500",
    "FastAPI ответит 422: `abc` не целое число, функция не вызовется",
    "FastAPI ответит 404",
    "FastAPI подставит 0"
  ],
  "answer": [1],
  "explanation": "Аннотация `item_id: int` заставляет FastAPI проверить параметр до вызова функции. Если текст не превращается в целое число, клиент получает `422` с описанием ошибки. Функция не вызывается, поэтому `500` не будет; `404` FastAPI отвечает только на адрес, которого нет среди маршрутов; значение за клиента FastAPI не подставляет."

```

Обработчик объявлен как `@app.get("/items/{item_id}")` и `def get_item(item_id: int)`. Что произойдёт при запросе `GET /items/abc`?

```json
  "hints": ["Посмотрите, что сервер подсказывает заголовком ответа."],

    "Сменить метод на `POST`",
    "Считать, что сервер сломан"
  ],
  "answer": [1],
  "explanation": "`429 Too Many Requests` означает, что клиент превысил лимит частоты. Смена метода не обходит лимит, а сервер исправен: `429` — ошибка клиента, сбой сервера — это `5xx`."

```

Сервер ответил `429 Too Many Requests` с заголовком `Retry-After: 30`. Что должен сделать клиент?
