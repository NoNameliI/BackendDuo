# Установка Interactive Studio

1. Скачайте файл `Interactive-Studio-<версия>-Setup.exe` и запустите его двойным щелчком. Права администратора не нужны: программа ставится только для вашей учётной записи.
2. Если Windows показывает синее окно «Windows защитила ваш компьютер» (SmartScreen), это не вирус: у установщика нет платной цифровой подписи, поэтому Windows не знает издателя. Нажмите **Подробнее**, затем **Выполнить в любом случае**.
3. Следуйте шагам установщика (язык русский). На последней странице можно отметить «Добавить ярлык на рабочий стол».

Если у вас уже стояла прежняя версия под названием «PostgreSQL Interactive Studio», сначала удалите её (Параметры →
Приложения), не отмечая удаление данных: прогресс сохранится и подхватится новой версией.

## Проверка файла (по желанию)

Вместе с установщиком вам прислали файл `.sha256`. В PowerShell, в папке с файлами:

```powershell
Get-FileHash .\Interactive-Studio-<версия>-Setup.exe -Algorithm SHA256
```

Значение `Hash` должно совпасть с числом в файле `.sha256`. Если не совпало, скачайте файл заново.

## Где программа

Пуск → «Interactive Studio». Если отмечали ярлык, он есть и на рабочем столе. Закрытие окна сворачивает программу в трей (значок у часов); выйти совсем можно через меню значка → «Выйти».

## Удаление

Параметры Windows → Приложения → Установленные приложения → «Interactive Studio» → Удалить. По умолчанию ваш прогресс сохраняется: после повторной установки всё вернётся. Чтобы стереть и его, в окне удаления отметьте «Удалить данные приложения».
