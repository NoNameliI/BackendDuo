# Проверка установки на чистой Windows

Windows Sandbox каждый раз стартует с чистой системой (без Node, Rust и данных приложения).

1. Включите компонент (нужна Windows Pro/Enterprise/Education, один раз, затем перезагрузка): Win+R → `optionalfeatures` → «Песочница Windows», либо в PowerShell от администратора `Enable-WindowsOptionalFeature -Online -FeatureName Containers-DisposableClientVM`.
2. Соберите установщик: `npm run dist`. Файлы появятся в папке `release`.
3. Откройте `docs/clean-install-test.wsb` из `docs`: путь `..\release` в нём относительный. Если Sandbox не находит папку, укажите в `HostFolder` полный путь. Папка `release` появится в песочнице на рабочем столе, только для чтения.
4. Установите, запустите, пройдите один урок, удалите.

Что проверить:
- при запуске нет окна консоли;
- иконка и заголовок окна «Interactive Studio»;
- закрытие окна сворачивает в трей, значок есть, «Открыть студию» возвращает окно;
- в меню «Пуск» есть запись «Interactive Studio»; ярлык на рабочем столе появляется только если отмечен;
- при удалении есть флажок «Удалить данные приложения», по умолчанию снят;
- SmartScreen показывает предупреждение, как описано в `INSTALL.md`.
